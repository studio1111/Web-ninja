# KAGE — The Art of the Unseen

Complete React/Vite project with local cinematic hero video, mask cutouts, depth maps, responsive layout, scroll motion, and interactive WebGL mask relief.

## Run locally
```bash
npm install
npm run dev
```

## Publish on GitHub
1. Create or open the repository.
2. Upload the contents of this folder, preserving `src/assets`.
3. Run `npm install` and `npm run build`.
4. Deploy the generated `dist` folder with GitHub Pages, or use a Vite Pages workflow.

The large files are intentionally local: do not replace them with remote placeholder URLs.
