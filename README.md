# KAGE — The Art of the Unseen

A cinematic, responsive landing page inspired by the KAGE Japanese-mask showcase concept from the supplied tutorial and prompt.

## Included
- Full-screen cinematic hero with layered typography and scroll-linked parallax
- Origins, Craftsmanship, Collection, and final CTA sections
- Custom inline SVG mask artwork and subtle CSS depth/float treatment
- GSAP + ScrollTrigger entrance and scroll animations
- Mobile navigation and responsive layouts
- Reduced-motion fallback and scroll progress indicator
- GitHub Pages deployment workflow

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Assets and limitations
The current implementation is a functional front-end foundation. Typography loads from Google Fonts; GSAP loads from cdnjs; the hero background references an external Unsplash image. The mask artwork is original inline SVG with CSS depth effects, not a photogrammetric or sculpted 3D asset. The Higgsfield MCP generation attempt was rejected by the connected account because its plan requires Basic or higher, so no generated Seedance video or GPT Image assets were created. Replace the placeholder hero background and SVG mask illustrations with generated assets when generation access is available.

The layout and motion are inspired by the reference brief, not a pixel-for-pixel copy of every video frame.
